# SecHub Static v2

نسخه دوم رابط کاربری دایرکتوری رایتاپ‌های امنیتی فارسی.

- طراحی مدرن تیره با رنگ سبز امنیتی
- RTL فارسی و واکنش‌گرا
- جست‌وجو و فیلتر دسته‌بندی
- بخش موضوعات
- بدون بک‌اند و بدون ثبت‌نام

برای اجرا، `index.html` را باز کنید.


نسخه v3: بخش «موضوعات امنیتی» حذف شده است.

4. نسخه v4 به‌جای داده‌های نمونه، فهرست عمومی Pentester Land را از `https://pentester.land/writeups.json` دریافت می‌کند.
5. رابط، فیلترها، تاریخ‌ها و برچسب‌های رایج به فارسی نمایش داده می‌شوند و لینک/نام نویسنده/نام برنامه و منبع اصلی حفظ می‌شود.
6. متن کامل رایتاپ‌ها داخل `writeups.json` نیست؛ این فایل فقط متادیتای فهرست را ارائه می‌کند. ترجمه کامل مقاله‌ها باید جداگانه و موردبه‌مورد انجام شود.
7. منبع داده در خود سایت نیز درج شده است.

8. نسخه v5 شامل ۱۰ رایتاپ اول فهرست ارسالی کاربر است.
9. عنوان و نوع آسیب‌پذیری این ۱۰ مورد به فارسی اضافه شده و عنوان انگلیسی نیز برای ارجاع حفظ شده است.
10. این نسخه متادیتای ۱۰ رایتاپ را در `sechub-writeups-fa.json` نگه می‌دارد؛ ترجمه متن کامل مقاله‌ها به‌صورت جداگانه انجام می‌شود.

11. نسخه v6 تاریخ‌های رایتاپ‌ها را با تقویم جلالی/شمسی نمایش می‌دهد.
12. کلیک روی کارت رایتاپ اکنون صفحه داخلی همان رایتاپ در `writeups/` را باز می‌کند؛ لینک منبع اصلی داخل صفحه باقی می‌ماند.
13. برای هر ۱۰ رایتاپ صفحه مستقل ساخته شده است. محتوای کامل ترجمه‌شده مقاله‌ها به‌صورت مرحله‌ای داخل همین صفحات قرار می‌گیرد.
